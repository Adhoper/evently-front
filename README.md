# Evently Frontend

Frontend de Evently desarrollado con React, TypeScript, Vite y Tailwind CSS.

## Funcionalidades

- Catálogo y detalle de eventos
- Registro, inicio de sesión y roles
- Reservas, entradas digitales y QR
- Panel de organizador, asistentes y check-in
- Panel administrativo de usuarios, eventos y categorías
- Carga y vista previa de imágenes de eventos
- Modo claro/oscuro y diseño responsive

## Ejecución local

```bash
npm install
npm run dev
```

La URL del backend se configura en `.env` mediante `VITE_API_URL`.

## Validación

```bash
npm run lint
npm run build
```
