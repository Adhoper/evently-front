# 🌐 Evently – Frontend

**Evently** es una plataforma web para descubrir eventos, reservar entradas digitales y gestionar la asistencia mediante códigos QR.

La aplicación ofrece experiencias diferentes para usuarios, organizadores y administradores, con una interfaz moderna, responsive y compatible con modo claro y oscuro.

## ✨ Funcionalidades

- 🔐 Registro e inicio de sesión.
- 🔑 Recuperación de contraseña mediante correo electrónico.
- 🔎 Exploración y búsqueda de eventos.
- 🗂️ Filtros por categoría y fecha.
- 🎫 Reserva de entradas con disponibilidad real.
- 📱 Ticket digital con código QR.
- ❌ Cancelación de reservas.
- 👤 Sección de **Mis entradas**.
- 🧑‍💼 Panel para organizadores.
- 📅 Creación, edición, publicación y cancelación de eventos.
- 🖼️ Carga y gestión de imágenes para eventos.
- 👥 Consulta de asistentes.
- 📊 Estadísticas de reservas, ocupación y asistencia.
- 📷 Check-in mediante cámara y código QR.
- ⌨️ Check-in manual mediante código.
- 🛡️ Panel administrativo.
- 👥 Gestión de usuarios y roles.
- 🗂️ Gestión de categorías.
- 🌗 Modo claro y oscuro.
- 📱 Diseño responsive para móvil, tablet y escritorio.

## 👥 Roles

### Usuario

Puede explorar eventos, reservar entradas, consultar sus tickets digitales y cancelar reservas.

### Organizador

Puede crear y administrar eventos, subir imágenes, consultar asistentes, visualizar estadísticas y realizar check-in.

### Administrador

Puede supervisar la plataforma, gestionar usuarios, roles, eventos y categorías.
